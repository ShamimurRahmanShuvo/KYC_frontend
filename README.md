# KYC Frontend

A modern Know Your Customer (KYC) verification platform built with React and TypeScript.

## Features

- User registration and authentication
- Identity document upload and validation
- Face matching and biometric verification
- Passive and active liveness detection
- KYC application status tracking
- Real-time API integration
- Responsive and accessible UI
- Secure client-side validation

## Tech Stack

- React 18
- TypeScript
- React Router
- Material UI
- Vite

## Backend Integration

This application integrates with a FastAPI-based KYC microservice that provides:

- Document verification
- Face matching
- Liveness detection
- KYC workflow management
